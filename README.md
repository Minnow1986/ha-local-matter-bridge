# HA Local Matter Bridge

A Home Assistant custom integration that exposes Home Assistant entities as Matter bridge devices.

## Goals

- Local only
- No cloud dependency
- No subscriptions
- Alexa support
- Apple Home support
- Google Home support
- SmartThings support

## Current Status

Research and proof-of-concept stage.

## MVP

- Expose a Home Assistant switch
- Publish as Matter endpoint
- Discoverable by Matter controllers
